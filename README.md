A simple, interactive command-line Python application designed to track student names and academic scores efficiently. 

Features
- Add Students:Input and store student names mapped to their respective numerical grades using Python dictionaries.
- View Records:Display all stored student records dynamically in a clean console format.
- Input Error Handling:Uses `try-except` blocks to catch invalid inputs and prevent application crashes.
- Interactive Menu:*Continuous loop-driven user interface for smooth navigation.

Technologies Used
- Python (Dictionaries, While Loops, Conditional Statements, Exception Handling)
